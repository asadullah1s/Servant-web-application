# Servant-web-RENT A SERVANT

Complete Mobile App UI/UX & Functional Requirements

Tagline

Find. Verify. Hire.

App Purpose

Rent a Servant ایک professional service marketplace ہوگا جہاں customers اپنے گھر، office یا business کے لیے verified workers/service providers تلاش، compare اور hire کر سکیں گے۔

App کا basic concept inDrive کے request → offers → selection → booking model سے inspired ہوگا، لیکن:

* UI/UX مکمل طور پر original ہوگا۔
* Theme inDrive سے بالکل مختلف ہوگی۔
* Service categories domestic, household, childcare, office اور related services کے لیے ہوں گی۔
* Worker verification اس app کا سب سے اہم حصہ ہوگا۔
* Police Clearance Certificate ہر worker کے لیے mandatory ہوگا۔
